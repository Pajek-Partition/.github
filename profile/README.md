# Pajek - Large-network analysis for graphs you already assembled

## Pajek Highlights

- **Size First:** Pajek large network is meant for graphs with many vertices from a dataset you assembled, where a toy visualizer stalls.
- **Partitions As The Daily Object:** Pajek partition groups vertices you already classified (clusters, time slices, roles) so later reductions make sense.
- **.net As The Exchange:** Pajek .net graph is the classic file for a network you keep, readable by other academic tools you already use.
- **Reduction Before Pretty Layout:** Pajek social graph can shrink, extract, and bin a huge file so analysis happens on a piece you chose.
- **Not A Biology Pathway Seat:** Molecular omics maps belong in Cytoscape. Pajek’s culture is large social, citation, or infrastructure graphs you collected.

---

## What Is Pajek

Pajek is a Windows program for analysis and visualization of large networks. Researchers who already built an edge list that no longer fits a classroom sociogram open Pajek large network. Pajek partition is how they cut the vertex set. Pajek .net graph is how they store it. Pajek social graph is the usual story: collaboration, citation, trade, or communication data they assembled with permission.

The name is Slovenian for spider. The workflow is reduction: from a huge graph to a smaller one you can still interpret. Drawing every vertex is optional and often wrong. UCINET sits closer to matrix methods on moderate data; SocNetV sits closer to a drawn sociogram. Pajek sits on the large-file side.

Use datasets you collected, licensed, or were given for a project you administer. Keep partitions with the codebook. Do not scrape private accounts into a .net file.

## Starting with Pajek

Prerequisites: A PC you administer and an edge list or .net file from data you are allowed to analyze.

1. **Prepare:** Confirm vertex IDs in the dataset you assembled, and write a codebook for any groups.
2. **Configure:** Load the Pajek .net graph and attach a Pajek partition if you already have one.
3. **Test:** Compute a simple degree view on a subsample so Pajek large network is clearly reading the file.
4. **Refine:** Reduce or extract a component before attempting a full drawing of Pajek social graph.
5. **Apply:** Run the measures the project asked on that reduced piece.
6. **Maintain:** Version the .net with the codebook, and drop vertices you are not allowed to keep.

## Best Uses

- **Collaboration Graphs You Built:** Pajek social graph from co-authorship you are allowed to use.
- **Citation Files Too Big To Draw:** Pajek large network with reduction first.
- **Infrastructure Or Trade Edges You Collected:** Partitions by region you coded.
- **Teaching A Reduction Workflow:** A public dataset the course already licensed.
- **Not A Protein Pathway Figure:** Use Cytoscape for omics tables.
- **Not A Ten-Person Classroom Sociogram:** SocNetV may be enough there.
- **One Study Per .net:** Do not concatenate unrelated years without a partition.
- **Export After Reduction:** Pajek .net graph of the piece you will actually interpret.
- **Keep Scraped Private Ties Out:** Only ties you have a right to store.
- **Codebook Beside The Partition:** Pajek partition is meaningless without labels you wrote.
- **Degree Then Structure:** Look at size before a force layout of everything.
